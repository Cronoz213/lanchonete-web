# Lanchonete do Bairro — v1.0.0

Site oficial da Lanchonete do Bairro.

## Como usar
1. Abra o arquivo `index.html` no navegador.
2. Navegue pelo cardápio e promoções.
3. Clique em "Pedir" ou "Aproveitar" nos itens desejados.

## Arquivos
- `index.html` — Página principal
- `promocoes.html` — Página de promoções
- `style.css` — Estilos visuais
- `cardapio.js` — Lógica do cardápio
